# MeloX Release Notes / MeloX 更新日志

## iOS + Apple Watch

### 简体中文

- 增加了一比一还原的 Apple Music 26 歌词样式并作为默认值，之前的样式可切换至“自定义”样式后重新使用
- 增加了全新的 Apple Music 样式播放器背景，基于 Apple Music 26 一比一还原，可在设置中切换
- 增加了双人歌词对唱展示的支持
- 增加了多源歌词优选和手动选择（网易云音乐、99 音乐、AMLL）
- 添加了蜂窝网络音质设置 by takoyakiwhite
- 增加了多语言功能及相关翻译
- 修复了播放列表只会添加歌单前 100 首歌的问题
- 修复了播放器内前往艺人只能选择第一个艺人的问题 by takoyakiwhite
- 修复了自动混音执行时会卡顿一秒的问题 by takoyakiwhite

### English

- Added a faithful recreation of the Apple Music 26 lyrics style and made it the default; the previous look remains available by switching to the Custom style
- Added a new Apple Music player background faithfully recreated from Apple Music 26 and selectable in Settings
- Added duet lyric presentation
- Added automatic selection and manual switching among multiple lyric sources (NetEase Cloud Music, 99 Music, and AMLL)
- Added cellular audio-quality settings by takoyakiwhite
- Added support for multiple languages
- Fixed playlists adding only the first 100 tracks to the play queue
- Fixed artist navigation in the player allowing only the first artist to be selected, by takoyakiwhite
- Fixed a one-second stutter when AutoMix starts a transition, by takoyakiwhite
